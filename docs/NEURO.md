# Локальная нейросеть для КиберЩита

Инструкция: как поставить нейросеть на свой компьютер и подключить её к боту. Всё работает локально — сообщения никуда не уходят.

---

## 1. Что понадобится

- **ОС:** Linux (основная инструкция), Windows или macOS — команды почти те же.
- **ОЗУ:** минимум 4 ГБ, комфортно 8 ГБ.
- **Диск:** 5–10 ГБ свободно.
- **Процессор:** 4 ядра и больше. Видеокарта не обязательна, но с ней быстрее.
- **Интернет:** только для скачивания программы и модели. Дальше можно работать офлайн.

Проверить свой компьютер:

```bash
free -h          # сколько ОЗУ
nproc            # сколько ядер
df -h ~          # сколько места на диске
```

## 2. Установка Ollama

**Ollama** — самая простая программа для запуска нейросетей. Скачиваем с официального сайта: <https://ollama.com/download>

### Linux

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

Проверка:

```bash
ollama --version
```

Если команда не найдена — перезапусти терминал.

### Windows

1. Скачай установщик `OllamaSetup.exe` с сайта.
2. Запусти и установи.
3. Открой PowerShell и проверь: `ollama --version`.

### macOS

Скачай `Ollama-darwin.zip` с сайта, распакуй, перетащи в «Программы», запусти и проверь `ollama --version`.

## 3. Какие модели скачать

Модели в Ollama уже сжаты (квантование Q4) — это сильно экономит ОЗУ. Ниже — только лёгкие варианты.

| Модель | Команда | Размер | ОЗУ | Русский | Для кого |
|---|---|---|---|---|---|
| Qwen3 0.6B | `ollama pull qwen3:0.6b` | ~0.5 ГБ | 2 ГБ | слабый | совсем слабый ПК, простые ответы |
| Qwen3 1.7B | `ollama pull qwen3:1.7b` | ~1.4 ГБ | 4 ГБ | нормальный | **лучший баланс для слабого ПК** |
| Gemma 3 1B | `ollama pull gemma3:1b` | ~0.8 ГБ | 3 ГБ | средний | быстрые короткие ответы |
| Qwen2.5 1.5B | `ollama pull qwen2.5:1.5b` | ~1 ГБ | 3–4 ГБ | нормальный | стабильная альтернатива Qwen3 |
| Llama 3.2 3B | `ollama pull llama3.2:3b` | ~2 ГБ | 6 ГБ | средний | если есть 8 ГБ ОЗУ |
| Gemma 3 4B | `ollama pull gemma3:4b` | ~3.3 ГБ | 8 ГБ | хороший | 8–16 ГБ ОЗУ |
| Qwen3 4B | `ollama pull qwen3:4b` | ~2.6 ГБ | 8 ГБ | хороший | лучшее качество среди лёгких |

### Рекомендация

- **4 ГБ ОЗУ:** `qwen3:1.7b`
- **8 ГБ ОЗУ:** `qwen3:4b` или `gemma3:4b`
- **2 ГБ ОЗУ / очень старый ПК:** `qwen3:0.6b`

⚠️ TinyLlama, SmolLM2 и подобные модели размером до 1B по-русски отвечают плохо — для этого бота лучше Qwen или Gemma.

### Скачать и запустить

```bash
ollama pull qwen3:1.7b
ollama run qwen3:1.7b
```

Внутри появится приглашение `>>>` — можно писать вопросы. Выход: `/bye` или `Ctrl+D`.

Полезные команды:

```bash
ollama list          # какие модели скачаны
ollama ps            # что сейчас загружено в память
ollama rm qwen3:0.6b # удалить модель
```

Модели хранятся в `~/.ollama/models`.

## 4. Проверка через API

Ollama поднимает локальный сервер на `http://localhost:11434`.

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "qwen3:1.7b",
  "messages": [
    {"role": "system", "content": "Ты помощник по цифровой безопасности. Отвечай кратко и по-русски."},
    {"role": "user", "content": "Как распознать фишинг?"}
  ],
  "stream": false
}'
```

Ответ придёт в поле `message.content`.

## 5. Подключение к сайту

В проекте уже есть готовая структура и FastAPI-прокси:

```
botot/
├── app.py               # FastAPI + прокси к Ollama
├── server.py            # запуск: python server.py
├── static/
│   ├── index.html
│   ├── css/styles.css
│   └── js/              # data, core, ui, features, app, api
└── docs/NEURO.md
```

`app.py` отдаёт сайт и принимает запросы на `/api/chat` и `/api/status`. Браузер не обращается к Ollama напрямую — это обходит CORS и не раскрывает настройки модели.

Запуск:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python server.py
```

Или `uvicorn app:app --reload`. Открой <http://localhost:8000>.

Если Ollama слушает другой адрес или ты скачал другую модель:

```bash
OLLAMA_MODEL=qwen3:4b python server.py
OLLAMA_URL=http://127.0.0.1:11434 python server.py
PORT=8080 python server.py
```

На сайте есть переключатель **«Обычный» / «Нейро» / «Справочник»**:

- **Обычный** — мгновенные ответы по правилам и памяткам, без модели.
- **Нейро** — свободный диалог с локальной моделью через `/api/chat`. Если Ollama недоступна, бот автоматически отвечает по памяткам.
- **Справочник** — поиск по файлам из папки `knowledge/` по ключевым словам и синонимам. Документы можно добавлять на ходу, перезапуск не нужен.
- Кризисные сообщения (угрозы жизни, самоповреждение, потеря денег) в любом режиме обрабатываются правилами и подсказывают 112/102.

### Важно

- Сначала оставь текущие правила распознавания кризиса — они срабатывают мгновенно и предсказуемо.
- Нейросеть подключай как второй уровень: для свободного текста и сложных формулировок.
- Таймаут первый раз может быть 20–60 секунд: модель загружается в память.
- Держать модель в памяти: параметр `"keep_alive": "30m"` в запросе.

## 6. Что сказать нейросети (промпт)

Системный промпт уже встроен в `app.py` (константа `SYSTEM_PROMPT`). Его можно усилить так:

- запретить выдумывать номера телефонов и адреса;
- требовать структуру: «поддержка → что делать → куда обратиться»;
- запретить просить персональные данные;
- при признаках самоповреждения или угрозы жизни сразу давать 112 и телефон доверия;
- не обещать анонимность, которую бот не может гарантировать;
- не давать инструкций по взлому, слежке и обходу защиты.

---

## 7. Приватность и закон

- Локальная модель обрабатывает сообщения **на твоём компьютере**, данные никуда не отправляются.
- Если позже захочешь облачный API (GigaChat, YandexGPT, DeepSeek) — сообщения несовершеннолетних уходят на чужой сервер. Это требует политики обработки данных и соблюдения 152-ФЗ.
- Для сайта с реальными пользователями нужны: политика конфиденциальности, ограничение логов, отсутствие сбора ФИО/телефонов, понятный дисклеймер «бот не заменяет специалиста».
- Не храни переписку с детьми дольше, чем нужно, и не привязывай её к аккаунту без согласия.

## 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| `ollama: command not found` | перезапусти терминал или переустанови Ollama |
| Модель долго отвечает в первый раз | это нормально, она загружается в ОЗУ |
| Компьютер зависает | возьми модель меньше, например `qwen3:0.6b` |
| `model requires more system memory` | не хватает ОЗУ — нужна модель меньше |
| Сайт не подключается к API | проверь, что Ollama запущена: `ollama ps` |
| `502` от сервера | запусти `ollama run qwen3:1.7b` и проверь имя модели |
| Ответы не по-русски | укажи язык в системном промпте и возьми Qwen/Gemma |
| Порт 8000 занят | поменяй `PORT=8080` при запуске |

Логи Ollama (Linux):

```bash
journalctl -u ollama -f
```

## 9. Короткий чек-лист

1. Установить Ollama.
2. `ollama pull qwen3:1.7b` (или другую из таблицы).
3. `ollama run qwen3:1.7b` — проверить, что отвечает.
4. Запустить `python server.py`.
5. Открыть `http://localhost:8000`.
6. Подключить на фронте `fetch('/api/chat')` вместо (или вместе с) правилами.
