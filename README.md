# КиберЩит

Анонимный чат-бот по профилактике мошенничества, кибербуллинга и вербовки. Работает на локальном компьютере: обычный режим — правила, режим «Нейро» — локальная модель через Ollama. Бэкенд — FastAPI.

## Быстрый старт

```bash
# 1. Ollama и модель (если ещё не установлены)
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen3:1.7b

# 2. Зависимости Python
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Сервер
python server.py
```

Или через uvicorn:

```bash
uvicorn app:app --reload
```

Открыть: <http://localhost:8000>  
Документация API: <http://localhost:8000/docs>

Подробная инструкция по установке и моделям: [docs/NEURO.md](docs/NEURO.md).

## Режимы

- **Обычный** — мгновенные ответы по правилам. Без модели и без задержек.
- **Нейро** — свободный диалог с локальной моделью. Если Ollama недоступна, автоматический откат к памяткам.
- **Справочник** — поиск по документам из папки `knowledge/`. Если под запрос подходит несколько статей, бот показывает подменю; выбранная статья открывается целиком. Сейчас в базе 57 статей УК РФ.
- Кризисные темы (угрозы жизни, самоповреждение, потеря денег) всегда идут через правила и подсказывают 112 / 102.

Выбор режима сохраняется в браузере. Статус модели или количество документов виден в боковой панели.

## Настройки

```bash
OLLAMA_MODEL=qwen3:4b python server.py
OLLAMA_URL=http://127.0.0.1:11434 python server.py
PORT=8080 python server.py
```

### Запуск под путём домена

Фронтенд берёт пути к API относительно расположения `static/js/api.js`, поэтому его можно разместить в подкаталоге. Если прокси передаёт префикс без обрезки:

```bash
ROOT_PATH=/bot python server.py
```

Тогда сайт и API доступны по адресам `/bot/`, `/bot/api/chat` и т.д.  
Если nginx обрезает префикс:

```nginx
location /bot/ {
    proxy_pass http://127.0.0.1:8000/;
}
```

`ROOT_PATH` в этом случае не нужен.

## API

- `GET /health` — проверка сервера.
- `GET /api/status` — статус Ollama и модели.
- `POST /api/chat` — чат бота (`message`, `history`).
- `GET /api/knowledge` — список документов справочника.
- `GET /api/knowledge/doc?id=...` — полный текст документа.
- `POST /api/search` — поиск по справочнику (`query`, `limit`).
- `GET /v1/models` — список моделей в формате OpenAI.
- `POST /v1/chat/completions` — OpenAI-совместимый чат, включая `stream: true`.

## Приватность

- Обычный режим: сообщения обрабатываются в браузере.
- Нейро: сообщения уходят только на локальный Ollama (`localhost`).
- Отчёты и статистика хранятся в локальном хранилище браузера и удаляются из панели «Анонимность и данные».
- Бот не запрашивает ФИО, телефон, адрес и данные карт.
