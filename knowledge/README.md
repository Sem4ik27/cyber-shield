# Справочник

Сюда можно складывать документы, которые бот будет искать в режиме **«Справочник»**.

Сейчас добавлено 57 статей УК РФ по темам: мошенничество и хищения, киберпреступления, угрозы и травля, вербовка, терроризм и экстремизм, вовлечение несовершеннолетних, наркотики и оружие. Для 9 базовых статей сохранены краткие памятки, ниже добавлен полный текст статьи.

## Поддерживаемые файлы

- `.md` и `.txt`
- кодировка UTF-8 (CP1251 тоже читается)
- вложенные папки поддерживаются

## Формат

```md
# Статья 159 УК РФ — Мошенничество

## Суть
Краткое описание статьи.

## Ответственность
Что грозит нарушителю.

## Ключевые слова
мошенничество, обман, деньги, карта
```

- Первая строка `# ...` — название документа. В названии желательно указать номер статьи.
- Разделы `## ...` индексируются отдельно — так поиск точнее.
- Файлы `README.md` и файлы, начинающиеся с `_`, не индексируются.
- Перезапускать сервер после добавления файлов не нужно: справочник перечитывается при изменении.
- Обновить набор статей можно скриптом `tools/fetch_uk.py` (тексты берутся из открытой правовой базы zakonrf.info).

## Важно

Файлы в этой папке — **краткие справки**, а не официальные тексты. Для юридически точной работы замените их официальными редакциями статей УК РФ. Бот не заменяет юриста.
